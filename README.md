# FantasyEarthZero-npc

FantasyEarthZero npc data

NPCモデル **3種 / 53モデル** を収録しています。各モデルは Blender 用 (`Blender/*.blend`) と元データ (`Model/*.mdl`, `*.tex`, `*.ans`) があります。

> プレビュー画像は各 .blend を Blender 5.2 (EEVEE) で自動レンダリングしたものです（正面やや右上から、アニメーション初期フレームのポーズ）。
> 情報欄はレンダリング時点の値です。
